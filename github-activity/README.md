# github-activity

A CLI tool to fetch and display the recent activity of any GitHub user directly in your terminal.

## Installation
```bash
pip install github-activity
```

## Usage
```bash
github-activity <username>
```

## Example
```bash
github-activity torvalds
```

## Development
```bash
git clone https://github.com/YOUR_USERNAME/github-activity.git
cd github-activity
python -m venv .venv
source .venv/bin/activate
pip install -e .
```
